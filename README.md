## 🚀 About / アプリについて
シンプルで直感的な To-Do リストアプリです。iPhone (iOS) などのスマートフォンでの利用に最適化されており、アプリのようにホーム画面に追加して使用できます (PWA)。

## ✨ Features / 主な機能
*   **タスク管理**: タスクの追加、完了、削除
*   **カテゴリ分類**: 色分けされたタグでタスクを整理
*   **履歴機能**: 削除したタスクの確認と復元
*   **ダークモード**: 目に優しいダークテーマ搭載
*   **データ保存**: ブラウザを閉じてもデータが消えない (LocalStorage)
*   **PWA対応**: ホーム画面に追加してネイティブアプリのように起動可能

## 📖 Usage / 使い方
1.  フォームにタスクを入力し、「追加」ボタンを押します。
2.  リストのチェックボックスで完了/未完了を切り替えます。
3.  ゴミ箱アイコンで削除（元に戻す通知あり）。
4.  右下のボタンから削除履歴を確認・復元できます。
